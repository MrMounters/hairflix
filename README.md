# Hairflix

A custom website and booking system for Hairflix Barbershop, with three verified Tempe and Scottsdale locations, real shop photography and Google review sources.

## Development

Use Node 22 or later. Run `npm install`, then `npm run dev`.

The booking calendar and $5 deposit checkout activate only after the shop's actual availability, durable storage and payment account are connected. No payment or successful appointment is simulated in the published site.

See `server/README.md` for configuration and API details.
